# Soldier Bullet System Implementation Plan

**Date:** July 9, 2025  
**Status:** Draft  
**Priority:** Medium  
**Dependencies:** Current soldier system in `nova.soldier.js`

## Overview

Transform the current soldier touch-based combat system into a bullet-firing system with targeting, projectiles, and enhanced combat mechanics. This will make soldiers more dangerous and strategic while allowing for player skill-based evasion.

### 3. Bullet Physics System
```javascript
class Bullet {
    constructor(x, y, targetX, targetY, speed) {
        this.sprite = new bullets.Sprite(x, y, bulletConfig.width, bulletConfig.height);
        this.sprite.color = 'black';
        this.startPos = {x, y};
        this.distanceTraveled = 0;
        this.fadeTimer = 0;
        this.active = true;
        
        // Calculate velocity vector for straight-line movement
        const angle = Math.atan2(targetY - y, targetX - x);
        this.velocity = {
            x: Math.cos(angle) * speed,
            y: Math.sin(angle) * speed
        };
    }
    
    update() {
        if (!this.active) return;
        
        // Move bullet
        this.sprite.x += this.velocity.x;
        this.sprite.y += this.velocity.y;
        this.distanceTraveled += speed;
        
        // Check max distance
        if (this.distanceTraveled >= bulletConfig.maxTravelDistance) {
            this.startFading();
        }
        
        // Handle fading
        if (this.fadeTimer > 0) {
            this.fadeTimer--;
            this.sprite.opacity = this.fadeTimer / bulletConfig.fadeTime;
            if (this.fadeTimer <= 0) {
                this.destroy();
            }
        }
    }
    
    startFading() {
        this.fadeTimer = bulletConfig.fadeTime;
    }
    
    destroy() {
        this.sprite.remove();
        this.active = false;
    }
}
```

## Implementation Phases

### Phase 1: Basic Bullet System
1. **Create bullet management system**
   - Add bullet Group to main game file
   - Implement basic Bullet class with kinematic movement
   - Add bullet removal when reaching max distance

2. **Update soldier targeting**
   - Add distance-based target detection
   - Replace touch-based combat with firing mechanism
   - Implement basic straight-line shooting (no leading yet)

3. **Basic collision detection**
   - Bullet vs Player (health damage)
   - Bullet vs Zombie (instant kill)
   - Bullets stop on first hit

### Phase 2: Advanced Targeting
1. **Implement target leading**
   - Calculate target velocity vectors
   - Predict future target position
   - Aim bullets at predicted location

2. **Add closest-target priority**
   - Distance calculation for all valid targets
   - Priority targeting system

3. **Fire rate limitation**
   - Add timing controls to soldier firing
   - Configurable fire rate parameter

### Phase 3: Visual Effects & Polish
1. **Muzzle flash system**
   - Brief visual effect when soldier fires
   - Coordinate with gunshot sound

2. **Bullet fade-out**
   - Gradual opacity reduction
   - Smooth removal from game

3. **Friendly fire system**
   - Bullets can hit soldiers, humans, doctors
   - Collision detection for all entity types

### Phase 4: Configuration & Balance
1. **Make all values configurable**
   - Sensing distance, bullet speed, fire rate
   - Easy parameter tuning for game balance

2. **Player health system**
   - Implement 3-point health for player
   - Health display in UI
   - Health regeneration mechanics (if desired)

3. **Testing and balance tuning**
   - Playtest for difficulty
   - Adjust parameters based on game feel

### Main Game Loop Integration
```javascript
// In playloop() function
for (let soldier of params.soldiers) {
    soldier.move(params.player, params.zombies);
    soldier.checkAndFire([...params.zombies, params.player]);
    soldier.display();
}

// New bullet update loop
for (let bullet of params.bullets) {
    bullet.update();
    
    // Collision detection
    if (bullet.overlaps(params.player) && bullet.active) {
        params.player.takeDamage(1);
        bullet.destroy();
        sound.gunshot.play();
    }
    
    // Zombie collisions
    for (let zombie of params.zombies) {
        if (bullet.overlaps(zombie) && bullet.active) {
            zombie.kill();
            bullet.destroy();
            sound.gunshot.play();
            break; // Stop on first hit
        }
    }
    
    // Friendly fire
    for (let entity of [...params.soldiers, ...params.humans, ...params.doctors]) {
        if (bullet.overlaps(entity) && bullet.active) {
            entity.kill();
            bullet.destroy();
            sound.gunshot.play();
            break;
        }
    }
}
```

## Risks and Mitigation

**Risk:** Bullets too fast/slow affecting game balance  
**Mitigation:** Highly configurable parameters for easy tuning

**Risk:** Target leading makes game too difficult  
**Mitigation:** Adjustable leading factor, can be disabled if needed

**Risk:** Friendly fire makes game unplayable  
**Mitigation:** Configurable friendly fire toggle, careful balance testing

**Risk:** Performance issues with many bullets  
**Mitigation:** Bullet lifecycle management, maximum bullet limits
